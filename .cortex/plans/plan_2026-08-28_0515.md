## MCP Economic Data Server — Implementation Plan

Your project currently has static macro data in `DIM_EXTERNAL_MACRO` (222 rows). We'll build a live MCP server that fetches state-level economic indicators from official APIs and exposes them as tools the Cortex Agent can call.

### Architecture

```
Cortex Agent (INTERACTIVE_DEMANDSENSING_AGENT)
    │  MCP protocol (stdio or SSE)
    ▼
MCP Server (Python, new service in docker-compose)
    │  REST API calls
    ▼
BLS API + FRED API (official data sources)
    │
    ▼
Snowflake DIM_EXTERNAL_MACRO (enriched with live state-level data)
```

### Implementation Steps

**1. Create MCP Server (`backend/mcp_economic_server/`)**
- `server.py` — Main MCP server using `mcp` Python SDK
- `tools/inflation.py` — BLS CPI-U data fetcher (state/metro level)
- `tools/unemployment.py` — BLS LAUS data fetcher (state level)
- `tools/cost_of_living.py` — FRED + C2ER proxy for COLI
- `tools/demand_correlation.py` — Queries Snowflake for historical correlation
- `config.py` — State-to-BLS-series mapping, FIPS codes
- `requirements.txt` — mcp, httpx, snowflake-connector-python

**2. State-Level Data Mapping (`backend/mcp_economic_server/mappings/`)**
- BLS series ID mapping for all 50 states + DC
- FRED series codes for supplementary indicators
- Region-to-state mapping aligned with your 5 regions (NE, SE, SC, MW, W)

**3. Snowflake Integration**
- Create `DIM_STATE_ECONOMIC_INDICATORS` table for caching fetched data
- Stored procedure to refresh from MCP server on schedule
- Update semantic model to include new economic indicator dimensions

**4. Docker Integration**
- Add `mcp-server` service to `docker-compose.yml`
- Expose on internal port for the Cortex Agent to connect

**5. Cortex Agent Wiring**
- Register MCP server with the `INTERACTIVE_DEMANDSENSING_AGENT`
- Add system prompt instructions for when to invoke economic tools

**6. Frontend — Wire up the existing "MCP Server" tab**
- Show server health, last fetch timestamps, data freshness

### API Keys Required
- **BLS API Key** (free, 500 req/day) — from `api.bls.gov`
- **FRED API Key** (free, 120K req/day) — from `fred.stlouisfed.org`

# Autonomous Module Report Redesign — Updated Plan

## Key Design Decisions (from your clarifications)
- **Pipeline runs ALL 3 personas at once** — one click triggers 3 pipeline calls (parallel). All data artifacts are created together. Only the selected persona's tab consumes/renders the relevant artifacts.
- **Per-persona tabs** — user selects which persona's report to view. Tabs: Demand Planner → Supply Planner → Director of Demand Planning (this sequence).
- **Persona dropdown is irrelevant for interactive module** — it's a different CoWork agent, so no changes needed there.
- **Static "HOW TO READ IT" sidebar** per chart + **AI narrative paragraph below** each visualization.
- **Heatmap**: Department-level aggregation first, with drill-down filter into sub-categories.
- **Temporary backend mapping** until Part A deploy batch lands: all 3 new personas map to existing "Supply Chain Director" backend persona (which produces real data). SQL queries do the per-persona department filtering.

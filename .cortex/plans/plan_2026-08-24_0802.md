### 1. TRIGGER MECHANISM: When Does the Loop Fire?

**Answer: Immediately on every negative feedback submission.**

The backend `/api/feedback` endpoint already persists the data. We add a **synchronous triage call** at the end of that endpoint — right after the INSERT succeeds, we call the triage procedure. This means:

- Every thumbs-down triggers instant classification
- No batch scheduling needed — the user's feedback is triaged in real-time
- Remediation generation runs separately (called manually or on schedule) to allow human review

```
User clicks 👎 → Backend INSERT → Triage SP fires → Classification stored
                                                     ↓
              Admin reviews queue ← Remediation SP (manual/scheduled)
```

### 3. VERIFIED QUERY LOGIC: Enhance vs. Add

The core intelligence:

```
User reports "Inaccurate data" or "Didn't answer my question"
        │
        ▼
┌─────────────────────────────────────────────┐
│ SIMILARITY CHECK against existing 15 VQs    │
│ (Compare user_query to each VQ's question   │
│  using Cortex EMBED + cosine similarity)    │
└──────────┬──────────────────┬───────────────┘
           │                  │
    Match ≥ 0.75        No match found
           │                  │
           ▼                  ▼
    ┌──────────────┐   ┌──────────────┐
    │ ENHANCE MODE │   │   ADD MODE   │
    │ Replace the  │   │ Create brand │
    │ existing VQ  │   │ new VQ entry │
    │ with fixed   │   │              │
    │ SQL          │   │              │
    └──────────────┘   └──────────────┘
```

**ENHANCE MODE**: When the user's question semantically matches an existing verified query (e.g., "MAPE by region for Q2" matches `verified_query_03: "What is the forecast accuracy (MAPE) by region?"`), we **replace** the existing VQ's SQL with the corrected version rather than adding a duplicate.

**ADD MODE**: When no existing VQ covers this question pattern, we add a new one.

### 4. ADDITIONAL GAPS TO FILL

**A. Pattern Detection (repeat failures)**
- Track how many times the same `detected_intent` gets negative feedback
- If ≥3 negatives on the same intent within 7 days → auto-escalate priority to "critical"

**B. Persona-weighted Priority**
- VP-level personas (VP Supply Chain, VP Merchandising) get `priority = 'high'` automatically
- Analyst/Manager level stays `medium`

**C. Regression Tracking**
- After a fix is applied, track if the same question pattern gets positive feedback next time
- Column: `REGRESSION_STATUS` (improved | unchanged | regressed)

**D. Fix Versioning**
- Track which version of the VQ/instruction was in place when the failure occurred
- Enables rollback if a fix makes things worse

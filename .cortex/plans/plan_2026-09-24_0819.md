## Implementation Steps

### Step 1: Add `gunicorn` to `backend/requirements.txt`
Phase 3's requirements.txt is missing `gunicorn`, which the Dockerfile CMD will need. Add it to the list.

**File**: `Vibe-Analytics-Phase3/backend/requirements.txt`

### Step 2: Create `backend/Dockerfile`
Identical to Phase 2's — `python:3.11-slim`, install requirements, run Gunicorn on :5000.

**File**: `Vibe-Analytics-Phase3/backend/Dockerfile`
```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir --upgrade -r requirements.txt
COPY . .
EXPOSE 5000
CMD ["gunicorn", "--bind", "0.0.0.0:5000", "--workers", "1", "--threads", "8", "--timeout", "900", "app:app"]
```

### Step 3: Create `frontend/Dockerfile`
Identical to Phase 2's — `node:20-alpine`, npm install, build with BACKEND_URL arg, npm start.

**File**: `Vibe-Analytics-Phase3/frontend/Dockerfile`
```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package.json package-lock.json* ./
RUN npm install
COPY . .
ARG BACKEND_URL
ENV BACKEND_URL=$BACKEND_URL
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]
```

### Step 4: Create `.dockerignore` files (both services)
Prevents copying unnecessary files into Docker images (node_modules, .next, .git, etc.).

**File**: `Vibe-Analytics-Phase3/frontend/.dockerignore`
```

.git
```

**File**: `Vibe-Analytics-Phase3/backend/.dockerignore`

### Step 5: Update `docker-compose.yml` — change auth socket port
The current compose file hardcodes `8888:8888` for the auth socket, which conflicts with Phase 2. Change to `8889:8888`.

**File**: `Vibe-Analytics-Phase3/docker-compose.yml` — change line 6 from `"8888:8888"` to `"${SF_AUTH_SOCKET_PORT:-8889}:8888"`

### Step 6: Prepare `.env` for EC2 deployment

- Ensure `SNOWFLAKE_TOKEN` is set (PAT auth)

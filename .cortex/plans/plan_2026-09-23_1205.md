## Plan: Section 4 Act — Data-Driven Recommendation Cards

### Root Cause of $0 Cost
Cost comes 100% from the LLM prescriptive agent. The agent prompt schema uses `"cost_usd": 0` as a placeholder. The LLM echoes `0` when it fails to compute a real cost. No Snowflake query provides cost.

### Fix: Build cards from Snowflake data
`FACT_RISK_RECOVERY_CURVE` joined with `FACT_DEMAND_RISK` has real `INTERVENTION_COST_USD` (avg $661 per record, all non-zero), `BENEFIT_COST_RATIO`, `VALUE_AT_RISK_USD`, `DETECTION_CONFIDENCE`, `PRIMARY_DRIVER`, `RECOMMENDED_POSTURE`, `DAYS_TO_IMPACT` at Category L2 + Region grain.

### Validation Answers
- **Category**: `CATEGORY_L2` from `DIM_PRODUCT` (L2 level, not L3)
- **Region**: `REGION` from `FACT_DEMAND_RISK`
- **Impact**: `SUM(VALUE_AT_RISK_USD)` per L2+Region
- **Cost**: `SUM(INTERVENTION_COST_USD)` per L2+Region — real non-zero values
- **Confidence**: `AVG(DETECTION_CONFIDENCE)` — 0-to-1 scale, multiply by 100 for display
- **BCR**: `AVG(BENEFIT_COST_RATIO)` — shows return per dollar spent
- **Dedup key**: `CATEGORY_L2 || REGION` — one card per combination
- **Sample top 3**: Dairy+South-Central ($5.9M impact, $368K cost, 86%), Dairy+Southeast ($5M impact, $322K cost, 87%), Dairy+National ($2.4M impact, $230K cost, 90%)
